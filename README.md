# CCTV → סרטון קולנועי

סקיל ל-Claude שלוקח סרטון ממצלמת אבטחה ומצלם אותו מחדש כסרט, בייצור אחד של **Seedance 2.5** (דרך Higgsfield). הגרסה הקולנועית מסונכרנת למקור פריים מול פריים, באותה מהירות ובאותו תזמון. התוצר הוא רילס 9:16 שבו רואים את שתיהן יחד.

## איך זה עובד
1. **ניתוח:** Claude מפרק את הסרטון לפריימים כל רבע שנייה, ועוקב אחרי כל דמות וחפץ: מי זז, לאן, באיזו מהירות, ומאיפה כל אחד נכנס.
2. **מפת עולם, סיפור ומפת סנכרון:** מפה מלמעלה עם מרחקים במטרים, שרשרת סיבה ותוצאה, וחלוקה ל-10–14 שוטים. כאן הוא עוצר ומבקש ממך אישור.
3. **פרומפט מובנה אחד** (12–21 אלף תווים): כל שוט צמוד לטיימקוד של המקור, ובכל שוט מצב פתיחה, פעולות, מצב סיום ו-MUST NOT.
4. **לולאות בדיקה לפני ייצור:** הפרומפט נבדק מול הסרטון, שוט מול דף פריימים, ומתוקן שוב ושוב עד שסבב שלם לא מוצא אף טעות. רק אז נשלח לייצור. זה החלק שחוסך קרדיטים.
5. **ייצור:** קודם טיוטה זולה ב-480p, ובדיקת נאמנות מול המקור. רק אם היא עוברת, גרסת 1080p.
6. **עריכה:** רילס 9:16 עם המקור והגרסה הקולנועית מסונכרנים.

## דרישות
- **Claude** עם תמיכה בסקילים: Claude Code, או claude.ai עם הרצת קוד.
- **חיבור Higgsfield** (MCP) עם קרדיטים. לדוגמה, ל-16 שניות: טיוטה כ-48 קרדיטים, ‏1080p כ-256.
- **ffmpeg** ו-**ffprobe**.
- **Python 3** עם **Pillow** (`pip install pillow`).
- לשלב העריכה (לא חובה): **Playwright** לכתוביות, ו-**ElevenLabs** לסאונד.

## התקנה

**Claude Code, כפלאגין:**
```
/plugin marketplace add Refael97/cctv-to-cinematic
/plugin install cctv-to-cinematic@cctv-to-cinematic
```

**Claude Code, ידנית:** מעתיקים את התיקייה `skills/cctv-to-cinematic` אל `~/.claude/skills/`.

**claude.ai:** אורזים את התיקייה `skills/cctv-to-cinematic` כ-zip, ומעלים אותו בהגדרות, באזור ה-Skills.

## שימוש
שולחים ל-Claude את הסרטון וכותבים:
```
/cctv-to-cinematic תהפוך את הסרטון הזה לסרט
```
או פשוט: "תהפוך את סרטון מצלמת האבטחה הזה לגרסה קולנועית".

בדרך Claude ישאל אותך כמה דברים:
- **איזה חלון לשחזר**, אם הסרטון ארוך מ-30 שניות.
- **באיזו מהירות המקור מתנגן:** זמן אמת או הילוך איטי. אתה ראית את הסרטון, אז התשובה שלך קובעת.
- **אישור על הניתוח:** מפת העולם, הסיפור ומפת הסנכרון. תבדוק במיוחד מאיפה כל דמות נכנסת.
- **אישור עלות** לפני כל ייצור.
